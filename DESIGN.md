# DESIGN.md
# KHUSH KAPOOR — VISUAL DESIGN SYSTEM

---

# 01 — DESIGN PHILOSOPHY
The website should feel like:
A PHOTOGRAPHER'S MIND + A FILM OPENING + A FASHION EDITORIAL + A MODERN CREATIVE STUDIO

It should NOT feel like:
A photography template.

---

# 02 — EMOTIONAL GOAL
CURIOUS → INTRIGUED → IMMERSED → IMPRESSED → CONNECTED → READY TO CONTACT

---

# 03 — COLOR
- Primary background: `#050505`
- Secondary background: `#0A0A0A`
- Primary text: `#F1F0EC`
- Muted text: `#6B6B6B`
- Border: `#202020`
- Accent: Electric / cool blue `#258DFF` (used sparingly)

---

# 04 — TYPOGRAPHY
- Display: Modern geometric grotesk (Syne)
- Body: Neutral modern sans-serif (Inter)
- Metadata: Monospace (JetBrains Mono) — `01 / PORTRAIT`, `JAIPUR, INDIA`, `2026`

---

# 05 — TYPE SCALE
- Hero: 8vw–14vw
- Section Headings: 5vw–9vw
- Body: 18px–22px
- Metadata: 10px–13px

---

# 06 — GRID & SPACING
- Desktop: 12-column editorial grid
- Controlled asymmetry & generous negative space

---

# 07 — BUTTONS & UI
- Text + Arrow (`START A PROJECT →`, `EXPLORE THE WORK ↓`)
- No pill-shaped SaaS buttons
- Thin borders (`#202020`)

---

# 08 — FINAL DESIGN STATEMENT
THE WEBSITE SHOULD FEEL LIKE A FILM THAT HAPPENS TO BE A PORTFOLIO.
