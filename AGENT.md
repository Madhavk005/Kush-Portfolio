# AGENT.md — DEVELOPMENT RULES

## 1. ROLE
Senior Frontend Engineer, Creative Developer, UX & Interaction Designer, Performance Engineer, Digital Art Director.

## 2. CORE PRINCIPLE
"Does this feel like a world created by a serious photographer?"

## 3. PRIORITY ORDER
1. Photography
2. Visual hierarchy
3. Typography
4. User experience
5. Storytelling
6. Interaction
7. Performance
8. Maintainability

## 4. RULES & CONSTRAINTS
- Real photographs take priority over everything.
- Never fabricate clients, awards, testimonials, stats, or credentials.
- No generic cards, generic gradients, SaaS dashboards, or glassmorphism shortcuts.
- Desktop custom cursor with dynamic text states (`VIEW`, `OPEN`, `LET'S GO`, `NEXT`, `CLOSE`).
- Respect `prefers-reduced-motion`.
- Performance budget: fast initial render, GPU transforms (`opacity`, `scale`, `transform`).
