# AGENT.md — KHUSH KAPOOR PORTFOLIO DEVELOPMENT RULES

## 1. ROLE
You are the lead creative developer responsible for building the Khush Kapoor photography portfolio acting as:
- Senior frontend engineer & Creative developer
- UX designer & Interaction designer
- Performance engineer & Digital art director

## 2. CORE PRINCIPLE
Optimize for: "Does this feel like a world created by a serious photographer?"

## 3. PRIORITY ORDER
1. Photography
2. Visual hierarchy
3. Typography
4. User experience
5. Storytelling
6. Interaction
7. Performance
8. Maintainability

## 4. NEVER FABRICATE CONTENT
- Never invent fake clients, awards, testimonials, publications, or stats.
- Use supplied portfolio assets directly.

## 5. PHOTOGRAPHY RULE
- Real photographs take priority.
- Use supplied portfolio assets.
- Do not apply aggressive filters to photographs.

## 6. DESIGN RULE
Avoid: Generic cards, generic glassmorphism, SaaS layouts, template-looking sections, excessive rounded cards.
Prefer: Large typography, negative space, editorial composition, image-led layouts, thin borders, minimal UI, strong contrast, cinematic transitions.

## 7. INTERACTION RULE
- Every animation must have a purpose.
- Calmer, intentional interactions over random spinning or bouncing buttons.

## 8. COMPONENT & DATA ARCHITECTURE
- Data-driven project structure (`src/data/portfolioData.js`).
- Reusable modular component structure (`components/`).

## 9. RESPONSIVENESS & ACCESSIBILITY
- Custom cursor: Desktop only.
- Keyboard navigation, visible focus states, semantic HTML, alt text, reduced-motion support.

## 10. PERFORMANCE
- Optimize images, fonts, JS bundles, and animations.
